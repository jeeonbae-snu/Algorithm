 GitHub 업로드 명령 (사용자 PC에서 직접 실행)
================================================================

샌드박스에서는 Windows측 .git 디렉터리 권한 때문에 git add/commit이
불가합니다. 아래 절차를 PowerShell 또는 Git Bash에서 직접 실행하세요.

------------------------------------------------------------
1. 폴더로 이동
------------------------------------------------------------
   cd C:\Users\jeeon\Desktop\Algorithm-main

------------------------------------------------------------
2. 변경사항 확인 (124개 파일 예상)
------------------------------------------------------------
   git status --short

------------------------------------------------------------
3. 전체 스테이징
------------------------------------------------------------
   git add -A

------------------------------------------------------------
4. 커밋
------------------------------------------------------------
   git commit -m "refactor: 코드 정리 및 헤더 정합성 수정

- README.md 재작성 (사이트별/난이도별 통계, 알고리즘 분포)
- 헤더 주석 추가 107개 파일 ([난이도] 문제명 / 분류 / 접근)
- Dead code 정리 36개 파일
- 잘못된 '접근:' 헤더 11개 수정 (BFS/DFS 보일러플레이트 → 실제 알고리즘)
- 점검_보고서.md / 변경_요약.md 갱신
- 240개 .py 파일 py_compile 통과 확인"

------------------------------------------------------------
5. 푸시
------------------------------------------------------------
   git push origin main

   (인증 필요 시 GitHub 토큰/SSH 키 사용)

------------------------------------------------------------
참고: 인덱스 락 파일이 남아있다면 먼저 제거
------------------------------------------------------------
   PowerShell:  Remove-Item .git\index.lock -Force
   Git Bash:    rm -f .git/index.lock
